==================================================================
OMNE SERIAL UNITS IMPORT GUIDE
Omne Pioneer  ·  Data Imports  ·  Physical Inventory
==================================================================

This guide explains how to fill in the Serial Units import file
for Serialized items. It covers the steps, every column, and how
rows are added.

The file has 3 required columns and 2 optional ones.


------------------------------------------------------------------
QUICK START
------------------------------------------------------------------

Step 1   Enter one row per serial unit on the Data Entry sheet,
         starting under the two example rows.

Step 2   Fill every column that ends in *. Use the exact values on
         the Valid Values sheet.

Step 3   Save the file, then in Data Imports open Physical
         Inventory, choose the Serialized tab and Import.

Step 4   Choose Review Data, fix any errors in the review, then
         Start Import to add the stock.


------------------------------------------------------------------
HOW ROWS ARE ADDED
------------------------------------------------------------------

Items            Every row names its item by Part Number. Only
                 Serialized items can be imported on this tab.

Serial numbers   Each row adds one unit. A serial number already
                 in use in Omne, or on two rows of the file, stops
                 that row.

Location         Stock is added to the location on the row. It
                 must already exist in Omne.


------------------------------------------------------------------
IMPORTANT NOTES
------------------------------------------------------------------

Errors     Rows with errors are not added until you fix them in
           the review.

Warnings   Rows with warnings are added as the message says, for
           example without a reason.

Headers    Do not rename, reorder or remove the header row.
           Required columns end in *.


------------------------------------------------------------------
COLUMNS
------------------------------------------------------------------

Part Number (required)
   The item the stock is added to. Must be a Serialized item in Item
   Library.
   Valid values: See Items on the Valid Values sheet
   Example: P-00891

Serial Number (required)
   The serial number printed on the unit. One row per unit. It must
   not already be in use in Omne or appear twice in the file.
   Example: SN-4001

Price
   Unit price, zero or more. Optional.
   Example: 24.50

Location (required)
   The location the stock is added to. Must be a location Omne holds.
   Valid values: See Location on the Valid Values sheet
   Example: Zone A-01

Reason
   Why stock is being added. Optional; an unrecognised reason is left
   blank.
   Valid values: System Startup, Found Item
   Example: System Startup
