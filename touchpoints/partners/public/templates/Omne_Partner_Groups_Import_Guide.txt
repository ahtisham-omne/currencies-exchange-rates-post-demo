==================================================================
Omne Partner Groups Import Guide
Omne Pioneer  ·  Partners Management
==================================================================

This guide explains how to fill in the Partner Groups import CSV.
It covers the steps, every column, and what the import does for a
new group and an existing group.

The CSV has 1 required column and 17 optional ones.


------------------------------------------------------------------
Quick Start
------------------------------------------------------------------

Step 1   Open the CSV. The first row is the column headers. Each
         row below it is one partner group.

Step 2   Two example rows are included to show the expected
         format. Delete both before you import.

Step 3   Fill in your groups. The one required column is marked
         with an asterisk and cannot be left blank: Group Name.

Step 4   Status, Country, and Group Scope are optional. What a
         blank value means depends on whether the group is new or
         already exists. See How Partner Groups Are Matched below.

Step 5   For columns that can hold a list, such as Group Scope,
         Linked Partners, Pricing Rules, and Carriers, separate
         each value with a pipe character ( | ). The pipe is on
         most keyboards above the backslash key, typed with Shift.
         Example: [ Vendor | Customer ]

Step 6   Save the file, then upload it in Omne under Partners
         Management, Partner Groups, Actions, Import Partner
         Groups.


------------------------------------------------------------------
How Partner Groups Are Matched
------------------------------------------------------------------

Omne matches each row by Group Name, then decides whether to
create a new group or update an existing one. Matching is not case
sensitive and ignores surrounding spaces.

For a New Group (Name Not in Omne)
----------------------------------
A new partner group is created.

  Status     Blank means Active.
  Template   Billing Type Domestic, Currency USD, and Credit
             Enforcement None when blank.
  Members    Linked Partners are attached by name; unknown names
             are dropped with a warning.

For an Existing Group (Name Already in Omne)
--------------------------------------------
The matching group is updated with the values you provide. A blank
cell leaves the existing value unchanged.

  Status    Blank keeps the current status.
  Members   Linked Partners replace the current members when
            given.


------------------------------------------------------------------
Copying from Another System
------------------------------------------------------------------

This template is plain text, so you can copy and paste from an
export of your old system. Line your old columns up with these
columns, fill in any that your old system did not have, and paste.
Enter phone numbers as you already have them, including any plus
sign or country code. You do not need to reformat or split them.


------------------------------------------------------------------
File Limits
------------------------------------------------------------------

Upload an Excel or CSV file up to 10 MB. Omne reads a single
sheet. Keep only the data sheet before you upload.


------------------------------------------------------------------
Important Notes
------------------------------------------------------------------

Linked Partners  Each name must match a partner that already
                 exists in Omne. Unknown names import with a
                 warning and are dropped. Primary Partners must be
                 a subset of Linked Partners.

Group Scope  Vendor, Customer, or both, separated with a pipe.
             Vendor Profiles apply only when the scope includes
             Vendor and Customer Profiles only when it includes
             Customer.

Credit Limit  Max Credit Limit must be 0 or more and Warning
              Threshold must be between 0 and 100. A non-numeric
              value blocks the row.

Currency, Payment Term, Pricing Rules  Use the exact names from
                                       the Valid Values sheet. An
                                       unknown value imports with
                                       a warning and the group
                                       keeps its default.

Empty Cells  Safe to leave blank in optional columns. Omne skips
             an empty cell and never overwrites an existing value
             with a blank.


------------------------------------------------------------------
Field Reference
------------------------------------------------------------------

Required Column
---------------

Group Name  The group's display name and the matching key. A new
            name creates a group, a matching name updates that
            group. Required.

Identity
--------

Status  Active or Inactive. Blank imports a new group as Active
        and leaves an existing group unchanged.

Country  Default country for partners created under this group.
         Pre-fills the partner's country and dial code.

Description  A short summary of the group's purpose or context. Up
             to 5000 characters.

Group Scope  Which partner types this template applies to: Vendor,
             Customer, or both. Optional.

Vendor Profiles  Vendor profiles enabled by default for partners
                 in this group.

Customer Profiles  Customer profiles enabled by default for
                   partners in this group.

Members
-------

Linked Partners  Existing partners to place in this group, by
                 name. Unknown names import with a warning and are
                 dropped.

Primary Partners  Linked partners that use this group as their
                  primary group. Must be a subset of Linked
                  Partners.

Template Configuration
----------------------

Billing Type  Domestic or International. Blank means Domestic.

Currency  Three-letter currency code inherited by partners in this
          group. Blank means USD.

Credit Enforcement  What happens when a partner in this group
                    reaches its credit limit. Blank means None.

Max Credit Limit  Default credit limit amount, 0 or more.
                  Non-numeric values block the row.

Warning Threshold (%)  Percentage of the credit limit at which a
                       warning is raised, 0 to 100.

Payment Term  The name of a payment term preset inherited by
              partners in this group.

Pricing Rules  Pricing rule preset names inherited by partners in
               this group.

Payment Methods  Accepted payment method types inherited by
                 partners in this group.

Carriers  Preferred shipping carriers inherited by partners in
          this group. The first one becomes the default.

Lists
-----
These columns can hold more than one value. Separate each value
with a pipe character ( | ), found above the backslash key using
Shift. Example: [ Vendor | Customer ]. For Linked Partners and
Primary Partners, each name must match a partner that already
exists in your Omne instance, and matching is not case sensitive.
