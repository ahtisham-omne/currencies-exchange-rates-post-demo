==================================================================
Omne Partners Import Guide
Omne Pioneer  ·  Partners Management
==================================================================

This guide explains how to fill in the Partners import CSV. It
covers the steps, every column, and what the import does for a new
partner and an existing partner.

The CSV has 2 required columns and 18 optional ones.


------------------------------------------------------------------
Quick Start
------------------------------------------------------------------

Step 1   Open the CSV. The first row is the column headers. Each
         row below it is one partner.

Step 2   Two example rows are included to show the expected
         format. Delete both before you import.

Step 3   Fill in your partners. The two required columns are
         marked with an asterisk and cannot be left blank: Partner
         Name, Primary Partner Group.

Step 4   Partner Groups must already exist in Omne, and the
         Primary Partner Group must be one of the groups listed on
         the row. Other set-value columns fall back to a safe
         default when blank. See How Partners Are Matched below.

Step 5   For columns that can hold a list, such as Partner Groups,
         Partner Type, Pricing Rules, and Carriers, separate each
         value with a pipe character ( | ). The pipe is on most
         keyboards above the backslash key, typed with Shift.
         Example: [ Vendor | Customer ]

Step 6   Save the file, then upload it in Omne under Partners
         Management, Partners, Actions, Import Partners.


------------------------------------------------------------------
How Partners Are Matched
------------------------------------------------------------------

Omne matches each row by Partner Name, then decides whether to
create a new partner or update an existing one. Matching is not
case sensitive and ignores surrounding spaces.

For a New Partner (Name Not in Omne)
------------------------------------
A new partner is created.

  Status         Blank means Active.
  Partner Type   Blank inherits the primary group's scope.
  Template       Currency, Payment Term, and Pricing Rules inherit
                 the primary group's template when blank.

For an Existing Partner (Name Already in Omne)
----------------------------------------------
The matching partner is updated with the values you provide. A
blank cell leaves the existing value unchanged.

  Status   Blank keeps the current status.
  Groups   Partner Groups and Primary Partner Group replace the
           current groups when given.


------------------------------------------------------------------
Copying from Another System
------------------------------------------------------------------

This template is plain text, so you can copy and paste from an
export of your old system. Line your old columns up with these
columns, fill in any that your old system did not have, and paste.
Enter phone numbers as you already have them, including any plus
sign or country code. You do not need to reformat or split them.


------------------------------------------------------------------
File Limits
------------------------------------------------------------------

Upload an Excel or CSV file up to 10 MB. Omne reads a single
sheet. Keep only the data sheet before you upload.


------------------------------------------------------------------
Important Notes
------------------------------------------------------------------

Partner Groups  Each group name must match a partner group that
                already exists in Omne. An unknown group blocks
                the row. The Primary Partner Group must be one of
                the groups listed in Partner Groups.

Partner Type  Vendor, Customer, or both, separated with a pipe.
              Vendor Sub-Types apply only to vendors and Customer
              Sub-Types only to customers; a sub-type without its
              type imports with a warning and is ignored.

Phone Number  Enter the number as you have it. Phone Country Code
              takes the dial code, such as +1 or +44. Both are
              kept as text so leading zeros and the plus sign are
              preserved.

Email  Must look like name@domain.com. An invalid email blocks the
       row.

Currency, Payment Term, Pricing Rules  Use the exact names from
                                       the Valid Values sheet. An
                                       unknown value imports with
                                       a warning and the partner
                                       keeps the group default.

Empty Cells  Safe to leave blank in optional columns. Omne skips
             an empty cell and never overwrites an existing value
             with a blank.


------------------------------------------------------------------
Field Reference
------------------------------------------------------------------

Required Columns
----------------

Partner Name  The partner's name and the matching key. A new name
              creates a partner, a matching name updates that
              partner. Required.

Primary Partner Group  The one group whose configuration this
                       partner inherits. Must be one of the
                       Partner Groups on the row. Required.

Identity and Grouping
---------------------

Status  Active or Inactive. Blank imports a new partner as Active
        and leaves an existing partner unchanged.

Partner Groups  Every partner group this partner belongs to. Each
                name must match an existing partner group.
                Separate several with a pipe character ( | ).

Partner Type  Vendor, Customer, or both. Blank inherits the
              primary group's scope.

Vendor Sub-Types  Vendor profiles to enable. Only applied when the
                  partner is a Vendor.

Customer Sub-Types  Customer profiles to enable. Only applied when
                    the partner is a Customer.

Contact
-------

Phone Country Code  Dial code for the phone number, such as +1 or
                    +44. Blank means +1.

Phone Number  The partner's main phone number, entered as you have
              it. Kept as text.

Email  The partner's main email address.

Website  The partner's website.

Address  The partner's address on a single line.

Description  A short summary of the partner's purpose or context.

Points of Contact  Contacts from the Contact Directory to attach
                   at partner level. Unknown names import with a
                   warning and are dropped.

Billing and Freight
-------------------

Currency  Three-letter currency code, such as USD or EUR. Blank
          inherits the primary group's currency, else the base
          currency (PKR).

Credit Enforcement  What happens when the partner reaches its
                    credit limit. Blank means None.

Payment Term  The name of a payment term preset. Blank inherits
              the primary group's term.

Pricing Rules  Pricing rule preset names to apply. Blank inherits
               the primary group's rules.

Payment Methods  Accepted payment method types.

Carriers  Preferred shipping carriers. The first one becomes the
          default.

Lists
-----
These columns can hold more than one value. Separate each value
with a pipe character ( | ), found above the backslash key using
Shift. Example: [ Vendor | Customer ]. For Partner Groups and
Points of Contact, each name must match a record that already
exists in your Omne instance, and matching is not case sensitive.
